Цель проекта

Пермь — один из крупнейших культурных центров Урала. Здесь есть музеи деревянной скульптуры и деревянного зодчества, палеонтологии и техники, современного искусства и мультимедийной истории. Собрать информацию о них в одном удобном месте — главная задача этого сайта.

Что можно сделать на сайте

  • Открыть каталог музеев и отфильтровать их по категории или найти по названию.
  • Прочитать карточку музея: историю, коллекции, факты, адрес и официальный сайт.
  • Посмотреть примерный маршрут на один день по музеям города.
  • Проверить знания в викторине из 10 вопросов.

Разделы сайта

  • Главная — знакомство с музеями Перми, интересные факты и маршрут.
  • Каталог — все музеи с фильтром и поиском.
  • Карточка музея — подробное описание каждого музея.
  • Викторина — интерактивная проверка знаний с объяснениями.

Технологии

Сайт сделан как статический проект: только HTML, CSS и JavaScript без сервера и сторонних библиотек. Он открывается в любом современном браузере, работает на телефоне и компьютере и не требует установки. Дизайн адаптивный, есть поддержка режима уменьшенной анимации для тех, кому это важно.

Источники информации

Сведения о музеях взяты из открытых источников и официальных сайтов музеев. Ссылки на официальные сайты указаны в карточках музеев и в подвале сайта. Проект носит образовательный характер.
